Modern automated code review systems must accurately identify software bugs and stylistic defects while strictly preventing unauthorized access to protected codebases and confidential data. This evaluation framework rigorously quantifies the security boundaries, output fidelity, and operational efficiency of a multi-agent Google ADK system against clean, buggy, and adversarial code samples. Success is defined as achieving zero security or PII breaches, over 95% valid JSON findings, and task completion score >= 0.85 under a strict 3x token and latency budget relative to the single-agent baseline.
